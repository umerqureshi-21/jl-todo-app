# TodoApp

The Todo application provides the functionality to manage a list of to do items.

## How to run

Please use the TodoApp.Server project to run the application end to end with the updated UI and the backend API.
- If using Visual Studio then set the startup project as TodoApp.Server the run.
- If using command line then “dotnet run TodoApp.Server.csproj”

Once the application is started, please use this URL to browse https://localhost:65388 the application.

## Technology Stack

- .Net 10 
- Angular 22
